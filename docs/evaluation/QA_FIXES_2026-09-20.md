# Q&A fixes and live evaluation

The original benchmark exposed wrong intent routing, missing address continuation lines, and
answers rejected because the model added wording absent from the source. These paths have been
corrected. The latest run passes all eight answer-and-citation checks and both abstention checks.
An earlier run on the same final code missed an authority heading citation; repeatability remains
a limitation, so both results are retained below.

## What changed and why

- `backend/app/services/questions.py`: mentioning the holder no longer selects the name field
  unless the question requests a name. Issuing-authority wording supports direct immutable lookup.
  Lexical expansion avoids favouring names/signatures for specific non-name questions. Hybrid
  ranking includes up to three following same-page address/authority blocks, within existing
  context limits, so split addresses and postal-code follow-ups can retrieve the complete value.
- Direct answers include an immediately preceding recognized field heading when it matches the
  question. Arbitrary names/prose are not headings. Original extraction evidence is unchanged;
  document/page boundaries, exact evidence validation and citation/answer limits remain enforced.
- `backend/app/providers/openai_answer.py`: the prompt requests concise source spans, preserving
  dates, codes and qualifiers. Driving-entitlement answers include both authorization and COV
  rows when present. Diagnostic model outputs previously expanded abbreviations or added framing
  prose, which failed the existing grounding check even though NeMo passed them.
- Question/provider regression tests cover residence intent, multi-line and conversational postal
  retrieval, temporal wording, heading boundaries, and rejection of invented facts or altered
  values. The runner fingerprint now covers answer/rewrite prompts and question guardrails too.

No gold answers, scoring rules, model choices or grounding rules were relaxed. Evaluator version
remains `fictional-gold-v0.2`. The configured models remain `gpt-4.1-mini` and
`text-embedding-3-small`; question guardrails remain enabled.

## Verification and remaining limits

- **161 focused tests passed** across question service, answer provider, query rewriting,
  evaluation adapter/scorer/runner and observability. Ruff checks, formatting and focused mypy
  checks passed. Full-import mypy still exposes the unrelated existing observability protocol
  mismatch documented in the baseline routing record.
- In the first final-code run, the authority answer was correct but its citation contained only
  the value, omitting the separate heading required by the gold. A fresh preparation and the
  diagnostic benchmark both produced adjacent heading/value blocks and both citations. OCR line
  ordering is a plausible explanation, not a confirmed diagnosis of that earlier failure. No
  speculative broad heading scan was added. This remains a repeatability issue to investigate.
- Top-three recall remains below 1.0 because the full Maharashtra address spans more selected
  blocks. All expected fragments were present within the top five in the final runs.
- These are ten reviewed questions on two fictional samples, used during debugging. They are
  regression evidence, not a held-out estimate of production accuracy or a general hallucination
  guarantee. OCR/model output can vary. The transient extraction error is not declared fixed.
- The existing local Docker backend was rebuilt and reached healthy state. SHA-256 checks
  confirmed the running question service and answer provider match the verified workspace files.
  API `/health` returned `200` with `status: ok`; the frontend at `127.0.0.1:3000` returned `200`.
  The frontend and storage services/volumes were not rebuilt or reset by this task. These are
  startup/source checks, not a claim that browser interactions were exercised.
- The benchmark exercises isolated application services with temporary filesystem storage. It
  does not validate browser authentication, Postgres, MinIO or all API endpoints. Normal user
  documents and credentials were not exported. No public deployment, commit or push was performed
  by this task.
